# TUPREL

**Typed Java data access, defined in a schema.**

Tuprel is an open-source relational data toolkit for Java. Define models in
schema.tuprel and generate Java models, inputs and typed PostgreSQL clients.
Keep queries, relation loading and transaction boundaries explicit.

## Explore Tuprel

- [Main project](https://github.com/tuprel/tuprel) — source, usage and current capabilities.
- [Documentation](https://github.com/tuprel/tuprel/tree/main/docs) — getting started, guides and reference.
- [Java playground](https://github.com/tuprel/tuprel/tree/main/examples/tuprel-playground) — a real consumer application using local PostgreSQL without Docker.

The current toolkit is a development preview built from source, with Java 21
and PostgreSQL as its baseline. No stable release or Maven artifact is published yet.
